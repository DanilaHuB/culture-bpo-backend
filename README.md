
Backend API для демонстрации культурных мероприятий (аналог Госуслуги.Культура).

Установка
1. Клонируйте репозиторий: `git clone https://github.com/ваш_логин/culture-bpo-backend.git`
2. Создайте виртуальное окружение: `python -m venv venv`
3. Активируйте вирт. окружение: `venv\Scripts\activate`
4. Установите зависимости: `pip install -r requirements.txt`
5. Настройте .env: SECRET_KEY=your_key
6. Миграции: `python manage.py migrate`
7. Создайте суперпользователя: `python manage.py createsuperuser`
8. Запустите: `python manage.py runserver`

API Эндпоинты
1        POST   Регистрация нового пользователя 
2        POST   Авторизация пользователя
3        POST   Выход из системы
4        POST   Обновление токена авторизации
5        GET     Получение профиля текущего пользователя
6        PUT     Обновление профиля пользователя 
7        GET     Получение списка всех мероприятий города
8        GET     Получение подробной информации о конкретном мероприятии
9        GET     Поиск мероприятий по ключевым словам, дате, категории или локации
10        GET     Получение списка категорий мероприятий 
11        GET     Получение списка мест проведения, локаций
12        GET     Получение списка избранных мероприятий пользователя
13        POST   Добавление мероприятия в избранное
14        DELETE        Удаление мероприятия из избранного
15        GET     Получение списка отзывов о мероприятии
16        POST   Добавление отзыва о мероприятии
17        PUT     Редактирование собственного отзыва
18        DELETE        Удаление собственного отзыва
19        POST   Создание нового мероприятия
20        PUT     Обновление информации о мероприятии


Структура
- models.py: Модели (User, Event, Review и т.д.)
- serializers.py: Сериализаторы с валидацией
- views.py: API Views
- urls.py: Маршруты

Технологии
- Django 5.2
- DRF
- JWT для авторизации
